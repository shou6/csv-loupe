# CSV Lens

[![CI](https://github.com/shou6/csv-lens/actions/workflows/ci.yml/badge.svg)](https://github.com/shou6/csv-lens/actions/workflows/ci.yml)

[English](README.md)

開発中に「この CSV の中身を確認したい」ときのための、読み取り専用のビューアです。大容量のファイルも扱えます。編集や分析はせず、中身を確認するまでの時間を短くすることに絞っています。

## 機能

- **読み取り専用**：`.csv` と `.tsv` を既定で表として開き、元のファイルには書き込まない
- **大容量でもすぐ開く**：「大きなファイルだが開くか」の確認を出さない。ヘッダーと先頭の行をすぐに表示し、行数は裏で数える
- **文字コードの判定**：UTF-8、BOM 付きの UTF-8、UTF-16 LE / BE、Shift_JIS（CP932）を扱う。推定した文字コードには `?` を付け、ツールバーで切り替えられる
- **区切り文字**：`.csv` はカンマ、`.tsv` はタブで開く。カンマ、タブ、セミコロン、パイプに切り替えられる
- **ヘッダーの判別**：先頭のレコードを残りと比べ、ヘッダーかどうかを判別する。判別できない時はヘッダーとして扱い、ツールバーに `?` を付ける。ツールバーで切り替えられる。ヘッダーが無い時は、列名を「列 1」「列 2」のように付ける
- **Quick Peek**：表示する行数を 1 / 10 / 100 から選んで構造を確かめる。All では全行を仮想スクロールで見られる
- **表**：見出しの固定、行番号、列幅の変更、折り返し、選んだセルと行の強調。セルの値の先頭と末尾の空白は取り除いて表示し、代わりに印を付ける
- **並べ替え**：列の見出しをクリックすると、その列で並べ替える。クリックするたびに昇順、降順、元の順に切り替わる
- **列の表示と非表示**：ツールバーの列の一覧で、列ごとに表示と非表示を切り替える。一覧は列名で絞り込める
- **Find**：まだ表示していない行も含め、ファイル全体を検索する。件数だけでなく、どの Row のどの列にあるかを一覧で示す。既定は部分一致で大文字と小文字を区別しない。区別する設定と、セル全体の一致に切り替えられる。× ボタンか `Esc` で検索をリセットする
- **Find Same Value**：選んだセルと値が完全に一致するセルを、全行・全列から探す（大文字と小文字を区別する）
- **Record View**：1 行を「列名と値」の縦の並びで表示する
- **Go to Row と Tail**：行番号を指定して移動する。末尾の行へ移動する
- **元のファイルとの対応**：選んだ行の Row と、元のファイルの行番号を表示する。標準のテキストエディタでその行を開ける
- **ファイルの変更の通知**：表示中にファイルが変わると、**再読み込み**ボタン付きの通知を出す
- **配色**：ティールを差し色にした独自の配色で、行を 1 行おきに色分けする。ライトとダークのテーマに合わせる。ハイコントラストのテーマでは、テーマの色を使う

## 使い方

1. `.csv` か `.tsv` を開くと、CSV Lens で表示される
2. ツールバーで表示する行数（1 / 10 / 100 / All）を選ぶ
3. セルを右クリックすると、次の操作を選べる
   - **セルをコピー**
   - **行をコピー**
   - **同じ値を検索**
   - **レコード表示を開く**
   - **元のファイルの該当行を開く**

- `Ctrl+F`（`Cmd+F`）で検索欄に移る。`Enter` で次の一致、`Shift+Enter` で前の一致へ移る
- `Ctrl+C`（`Cmd+C`）で選んだセルをコピーする
- セルをダブルクリックすると、その行をレコード表示で開く
- テキストとして編集したいときは、コマンドパレットで「エディターを再度開く」を実行し、「テキスト エディター」を選ぶ

## 注意

- Go to Row、Tail、並べ替えは、行数を数え終えてから使える
- 並べ替えは、1,000,000 行までのファイルで使える
- 改行コードは LF か CRLF に対応する。CR だけの改行には対応しない
- ローカルのファイルシステムにないファイル（仮想ファイルシステムなど）は、全体をメモリに読み込む
